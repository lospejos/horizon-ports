# Mythic Upgrades for Horizon

Eight gems and necoium with their ores and crystal geodes, and armour sets and tools that each have their own effect.

A port of [Mythic Upgrades](https://github.com/TriQue06/mythic-upgrades-multiloader/tree/1.20.1) 5.1.1 (Fabric 1.20.1) by TriQue to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`mythicupgrades-v0.2.0`](https://github.com/lavoide/horizon-ports/releases/tag/mythicupgrades-v0.2.0) holds `mythicupgrades.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
