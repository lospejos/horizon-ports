# Spelunkery for Horizon

Ores in granite, andesite, diorite and tuff, rough gems and raw nuggets, cave mushrooms, rock salt, glowsticks, rope ladders and mining tools.

A port of [Spelunkery](https://github.com/AstralOrdana/Spelunkery) 1.20.1-0.3.16 (Fabric 1.20.1) by Ordana and Keybounce to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-only, in `LICENSE`, with the GNU GPL v3 text it builds on in `COPYING`; see `NOTICE`, which also credits the two remixed sounds).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`spelunkery-v0.2.0`](https://github.com/lavoide/horizon-ports/releases/tag/spelunkery-v0.2.0) holds `spelunkery.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
